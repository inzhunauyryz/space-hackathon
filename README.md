# 🛰️ ЦУП «ИнтроСат» — приложение центра управления полётами

Хакатон-ЦУП 2026. Приложение принимает телеметрию учебного спутника «ИнтроСат»
от [data-emulator](https://github.com/mcc-hack/data-emulator) (или с реального устройства
через него), проверяет пакеты и показывает состояние аппарата оператору.

## Запуск (Windows / Linux / macOS)

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
# терминал 1 — эмулятор (из папки с emulator.py): выберите номер файла данных
python emulator.py
# терминал 2 — ЦУП
streamlit run app.py
```

Приложение сразу подключается к `http://127.0.0.1:8765/telemetry`.
Реальное устройство: `python emulator.py --source serial --port COM3`, приложение то же.

**Демо без эмулятора:** в боковой панели выберите «Воспроизведение файла» и
загрузите CSV (или положите файлы в папку `data/`).

## Что умеет

| Раздел ТЗ | Реализация |
|---|---|
| Приём телеметрии | фоновый поток опрашивает эмулятор, все поля переводятся в физические единицы |
| Статусы модулей | микроконтроллер, питание, датчик положения, 4 датчика света, маховик, канал связи — зелёный / жёлтый / красный |
| Графики | АКБ (с порогами), свет, акселерометр, гироскоп, магнитометр, маховик |
| 3D-вид | ориентация спутника в реальном времени (крен/тангаж по акселерометру, курс по магнитометру) |
| Нештатные ситуации | нет связи, пустой ответ, прекращение передачи, битые пакеты, вне диапазона, насыщение, отказ и «залипание» датчика, скачки, ошибки времени |
| Лог | каждый пакет пишется в `logs/telemetry_*.csv`; лог можно загрузить обратно и просмотреть |
| Команды | панель команд с журналом (см. ограничения) |

## Архитектура

- `telemetry.py` — разбор и проверка пакетов (`Validator`), без зависимостей от интерфейса
- `sources.py` — `HttpSource`, `FileSource`, `Collector` (поток, лог, события, состояние связи)
- `app.py` — интерфейс Streamlit
- `main.py` — консольная проверка файлов: `python main.py data/01_normal_flight.csv`

## Классификация пакетов

`NORMAL` · `WARNING` (внимание) · `FAULT` (авария) · `CORRUPTED` (пакет не разобран:
число полей, нечисловые значения, преамбула/постамбула). Маркеры преамбулы и постамбулы
определяются автоматически по первым пакетам.

## Ограничения

- Эмулятор работает только на передачу, поэтому без указанного COM-порта команды
  записываются в журнал как «имитация». Коды команд нужно подстроить под прошивку.
- Пороги напряжения АКБ и чувствительность детекции — в начале `telemetry.py`.
- 3D-вид ориентировочный: оси датчиков считаются совпадающими с осями корпуса.
